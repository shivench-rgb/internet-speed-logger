# Internet Speed Logger

A Python-based tool that checks internet speed and logs download speed, upload speed, and ping for tracking internet performance over time.

## Features

* Check download speed
* Check upload speed
* Measure ping
* Save speed test results
* Record date and time
* Simple command-line interface

## Technologies Used

* Python
* Speedtest
* CSV
* Datetime

## Project Structure

```text
internet-speed-logger/
│
├── speed_logger.py
├── requirements.txt
├── README.md
└── .gitignore
```

## Installation

Clone the repository:

```bash
git clone https://github.com/shivenchaware995-spec/internet-speed-logger.git
```

Open the project folder:

```bash
cd internet-speed-logger
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

## Run

```bash
python speed_logger.py
```

## Example Output

```text
Internet Speed Logger

Ping: 24 ms
Download Speed: 92.45 Mbps
Upload Speed: 41.28 Mbps

Speed test completed successfully.
```

## How It Works

The program performs an internet speed test and collects the following information:

* Ping
* Download speed
* Upload speed
* Date and time

The collected results can be stored and used to track internet performance over time.
